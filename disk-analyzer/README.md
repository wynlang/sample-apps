# Disk Analyzer

Analyze disk usage and file statistics for any directory.

## Features

- Disk usage analysis
- File and directory counting
- Large file detection
- Detailed reporting

## Usage

```bash
wyn main.wyn
./main.wyn.out
```

## What It Demonstrates

- `System::exec()` for system commands
- `File::write()` for reports
- String methods for data processing
- Real filesystem analysis

All stdlib modules available without import!
