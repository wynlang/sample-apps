# v1.11 Feature Showcase

Demonstrates all new features in Wyn v1.11 "The Developer Experience Release".

## Features Shown

- `enum.to_string()` — variant names instead of integers
- `for i, v in arr` — indexed iteration
- `"str" * n` — string repeat operator
- `int?` — optional type syntax
- `Type.new()` — static constructors

## Run

```bash
wyn run
```
