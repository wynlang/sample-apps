# CSV Data Processor

Parse and validate CSV data files with automatic analysis.

## Features

- CSV file parsing
- Data validation
- Pattern detection
- Summary generation

## Usage

```bash
wyn main.wyn
./main.wyn.out
```

## What It Demonstrates

- `File::read()` and `File::write()`
- `System::exec()` for data processing
- `.contains()` for validation
- `.trim()` for data cleaning

All stdlib modules available without import!
