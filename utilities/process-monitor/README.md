# Process Monitor

Monitor system processes, memory usage, and uptime in real-time.

## Features

- Real-time process listing
- Memory statistics
- System uptime tracking
- Process detection

## Usage

```bash
wyn main.wyn
./main.wyn.out
```

## What It Demonstrates

- `System::exec()` - Execute system commands
- String methods - `.trim()`, `.contains()`
- Real system integration
- Report generation

All stdlib modules available without import!
