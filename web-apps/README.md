# Web Applications

Web servers, APIs, and HTTP-based applications.

## Future Contributions

Examples of apps that belong here:

- **HTTP Server** - Simple web server with routing
- **REST API** - RESTful API with JSON responses
- **Static Site Generator** - Generate HTML from templates
- **Web Scraper** - Fetch and parse web pages
- **API Client** - Consume external APIs
- **Webhook Handler** - Process incoming webhooks
- **Proxy Server** - HTTP/HTTPS proxy
- **URL Shortener** - Link shortening service

## Requirements

Apps in this category should:
- Use HTTP/HTTPS protocols
- Handle requests and responses
- Parse/generate JSON or HTML
- Demonstrate networking best practices
- Include error handling for network failures
