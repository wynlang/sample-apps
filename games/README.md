# Games

Interactive games and simulations.

## Future Contributions

Examples of games that belong here:

- **Snake** - Classic snake game (terminal-based)
- **Tetris** - Block-stacking puzzle game
- **Tic-Tac-Toe** - Two-player strategy game
- **Hangman** - Word guessing game
- **Minesweeper** - Logic puzzle game
- **Chess** - Full chess implementation
- **Pong** - Classic arcade game
- **Roguelike** - Procedural dungeon crawler
- **Text Adventure** - Interactive fiction game
- **Sudoku Solver** - Puzzle solver with generator

## Requirements

Games in this category should:
- Be interactive and playable
- Have clear win/lose conditions
- Include game state management
- Demonstrate input handling
- Provide user feedback
- Be fun and engaging!
