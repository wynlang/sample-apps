# Wyn v1.6.0 Features

## What's New in v1.6.0

v1.6.0 improves the syntax and developer experience while maintaining full backward compatibility with v1.5.0.

### 1. Namespace Operator (::) ✅

**Clean enum constructor syntax:**

```wyn
// v1.5.0 (still works)
var result = Result_Ok(42)
var none = Option_None()

// v1.6.0 (cleaner)
var result = Result::Ok(42)
var none = Option::None()
```

**Works in pattern matching:**

```wyn
match result {
    Result::Ok(x) => x,
    Result::Err(e) => 0
}
```

**Benefits:**
- More readable code
- Familiar syntax (like Rust, C++)
- Clear namespace separation
- Backward compatible (old syntax still works)

---

### 2. Enhanced Error Messages ✅

**Before (v1.5.0):**
```
Error: Type mismatch
```

**After (v1.6.0):**
```
Error: Type mismatch at line 17
  Expected: int (integer)
  Got:      string (text string)
  Context:  argument 1

Note: use str_to_int() function to parse the string
```

**Features:**
- ✅ Color-coded output (red errors, yellow notes)
- ✅ Detailed type descriptions
- ✅ Context information
- ✅ Helpful conversion suggestions

---

### 3. New String Methods ✅

Added to standard library:

```wyn
// Replace substring
var text = "hello world"
var result = text.replace("world", "wyn")  // "hello wyn"

// Padding
var padded = "test".pad_left(8, "*")   // "****test"
var padded2 = "test".pad_right(8, "-") // "test----"

// Already existed in v1.5.0:
var starts = text.starts_with("hello")  // true
var ends = text.ends_with("world")      // true
```

**All methods:**
- `string.replace(old, new)` - Replace substring
- `string.pad_left(width, char)` - Left padding
- `string.pad_right(width, char)` - Right padding
- `string.starts_with(prefix)` - Check prefix
- `string.ends_with(suffix)` - Check suffix

## Migration from v1.5.0

### Backward Compatibility

**All v1.5.0 code continues to work!** You can migrate incrementally:

```wyn
// Old syntax (v1.5.0) - still works
var result = Result_Ok(42)

// New syntax (v1.6.0) - cleaner
var result = Result::Ok(42)

// Mix and match during migration
var old_style = Result_Ok(10)
var new_style = Result::Ok(20)
```

### Recommended Migration Path

1. **Start with new code** - Use `::` syntax in new files
2. **Update gradually** - Migrate existing code file by file
3. **Use find/replace** - `Result_Ok` → `Result::Ok`
4. **Test thoroughly** - Both syntaxes work identically

### Example Migration

**Before (v1.5.0):**
```wyn
enum Result {
    Ok(int),
    Err(string)
}

fn process(data: string) -> Result {
    if data.len() == 0 {
        return Result_Err("Empty input")
    }
    return Result_Ok(42)
}

fn main() -> int {
    var result = process("test")
    match result {
        Result_Ok(n) => {
            print(n.to_string())
            return n
        },
        Result_Err(msg) => {
            print(msg)
            return 0
        }
    }
}
```

**After (v1.6.0):**
```wyn
enum Result {
    Ok(int),
    Err(string)
}

fn process(data: string) -> Result {
    if data.len() == 0 {
        return Result::Err("Empty input")  // ✨ Cleaner
    }
    return Result::Ok(42)  // ✨ Cleaner
}

fn main() -> int {
    var result = process("test")
    match result {
        Result::Ok(n) => {  // ✨ Cleaner
            print(n.to_string())
            return n
        },
        Result::Err(msg) => {  // ✨ Cleaner
            print(msg)
            return 0
        }
    }
}
```

## Upgrading Sample Apps

### Data Processing Apps

**Use namespace operator for cleaner error handling:**

```wyn
// Before
fn validate(data: string) -> ValidationResult {
    return ValidationResult_Error("Invalid")
}

// After
fn validate(data: string) -> ValidationResult {
    return ValidationResult::Error("Invalid")
}
```

### Networking Apps

**Cleaner HTTP response handling:**

```wyn
// Before
match response {
    HttpResult_Success(data) => process(data),
    HttpResult_Error(code) => handle_error(code)
}

// After
match response {
    HttpResult::Success(data) => process(data),
    HttpResult::Error(code) => handle_error(code)
}
```

### All Apps

**Use new string methods:**

```wyn
// Text processing
var cleaned = text.replace("  ", " ")
var formatted = title.pad_left(20, " ")

// Validation
if url.starts_with("https://") {
    // Secure connection
}
```
